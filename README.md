A two-line robot confession: a household robot apologizes for waking the baby by announcing the end of her nap at full volume, and resolves to deliver news about quiet quietly, as a silent note instead. The program writes the two lines to /output/entry.txt.

## Run it

```sh
python3 main.py
```
